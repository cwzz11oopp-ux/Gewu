# 前端卡片布局与长文本显示设计

## 目标

本次只处理四项已确认的前端问题：历史研究标题过长、文献检索信息过多且论文标题过长、主工作区的文献与假设步骤顺序不一致，以及顶栏多余的“比赛模式”标签。后续关于部署路径、文献知识体系、本地文献上传、真实实验和 Skill 使用方式的讨论不在本次范围内。

## 根因

- 历史研究直接渲染 `RunRecord.title`，没有长度限制，也额外渲染 artifacts 数量和运行状态，导致左侧设置面板内容拥挤。
- 文献检索使用五列表格，固定展示标题、作者、年份、来源和验证状态；标题列没有宽度约束或截断规则，实际 DOI 值也没有显示。
- 主工作区按 A 研究主题、B 候选假设、C 文献检索排列，但左侧真实工作流是问题理解、文献检索、假设生成，两处顺序不一致。
- `App.tsx` 在顶栏独立渲染了奖杯图标和“比赛模式”标签。

## 交互与展示设计

### 历史研究

- 每条记录只显示 `RunRecord.problem_input`，不再显示 `RunRecord.title`、artifacts 数量或运行状态。
- 使用 Unicode 字符序列截取前 8 个字符；不足或等于 8 个字符时原样显示，超过 8 个字符时追加省略号 `…`。
- 历史研究按钮的原生 `title` 属性始终保存完整研究问题，鼠标悬停时可以查看全文。
- 删除按钮保留现有行为；历史记录行最小高度固定为 44px，并使用 `minmax(0, 1fr)` 内容列，避免长文本挤压删除按钮。

### 文献检索

- 卡片标题改为 B“文献检索与验证”，并在主工作区中紧跟 A“研究主题”。
- 使用固定布局的三列表格，只保留“论文标题”“作者”“DOI / 期刊”。桌面端列宽比例为 52%、28%、20%。
- 标题最多显示两行，超出后使用省略号；标题单元格的 `title` 属性保存完整标题。
- 作者数组使用逗号连接，最多显示一行，超出后使用省略号；作者单元格的 `title` 属性保存完整作者字符串。
- 第三列优先显示 `identifiers.doi` 的真实值。若 DOI 不存在或为空，则显示 `source` 期刊字段；两者都不存在时显示“期刊未知”。
- 删除年份、独立来源列和验证标签列。现有“仅使用已验证文献”提示与已验证数量继续保留，不改变数据筛选逻辑。
- 当视口宽度不超过 960px 时，表头隐藏，每条文献改为上下排列的三段式条目，以免窄屏出现横向滚动。

### 主工作区顺序与尺寸

- 组件渲染顺序调整为 A 研究主题、B 文献检索、C 候选假设、D 实验设计、E 实验执行。
- 桌面端主工作区使用命名网格区域：第一行是 `topic literature`，第二行是 `hypotheses hypotheses`，第三行是 `design experiment`。左列维持 0.95 份宽度，右列维持 1.45 份宽度。
- 因此 A 位于第一行左列，B 位于第一行较宽的右列，C 横跨第二行两列，D 位于第三行左列，E 位于第三行较宽的右列。
- 不超过 960px 时改为单列网格，依次排列 A、B、C、D、E。
- 左侧 `PipelineTimeline` 已经按文献检索先于假设生成排列，不修改其步骤或依赖关系。

### 顶栏

- 删除“比赛模式”标签及对应的 `Trophy` 图标导入。
- 保留 Qwen 配置、实验模式和研究员入口。
- 不修改页面其他位置关于运行模式的说明文字。

## 代码边界

- `frontend/src/utils/presentation.ts`：新增纯展示转换函数，负责 8 字截断、作者格式化和 DOI/期刊回退，不依赖 React。
- `frontend/src/components/ProjectSettingsModal.tsx`：使用研究问题摘要和完整悬停文本。
- `frontend/src/components/EvidenceTable.tsx`：使用展示转换函数并输出三列表格。
- `frontend/src/components/HypothesisBoard.tsx`：将步骤字母从 B 改为 C。
- `frontend/src/pages/WorkbenchPage.tsx`：把文献组件移动到候选假设之前。
- `frontend/src/App.tsx`：移除“比赛模式”标签和无用图标导入。
- `frontend/src/styles.css`：定义历史记录、三列文献表格、两行/单行截断、候选假设跨列和窄屏堆叠样式。

## 数据流与异常值

后端接口和数据模型不改变。展示函数只读取现有 `RunRecord.problem_input` 与文献对象的 `title`、`authors`、`identifiers.doi`、`source` 字段。空研究问题显示“未填写研究问题”；空标题显示“未命名论文”；空作者显示“作者未知”；DOI 和期刊均为空时显示“期刊未知”。这些回退仅影响显示，不写回后端。

## 验证标准

- Node 内置测试运行器先覆盖并验证纯展示函数：8 字边界、超过 8 字、Unicode 字符、空值、作者连接、DOI 优先和期刊回退。
- 前端 TypeScript 与 Vite 构建必须通过，且不得新增警告或类型错误。
- 浏览器在桌面宽度验证 A/B/C 顺序、B 位于宽列、C 横跨两列、历史删除按钮对齐和顶栏只移除比赛模式。
- 浏览器在不超过 960px 的窄屏验证文献条目上下排列、标题不溢出且页面无横向滚动。
- 悬停历史研究、论文标题和作者时，原生提示必须显示完整文本。
